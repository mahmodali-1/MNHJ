# لِنَنْهَض — الدليل التشغيلي للمشرف

موقع تفاعلي بملف واحد (`index.html`) يعرض منهج «لِنَنْهَض» التربوي (٥ وحدات، ٢٥ لقاءً) بطريقة تسهّل على المشرف التحضير والعرض.

A single-file, Arabic (RTL) website that presents the "Linanhad" youth curriculum (5 units, 25 sessions) to help supervisors prepare and present each session.

## ما الذي يحتويه كل لقاء؟

| التبويب | المحتوى |
|---|---|
| **مختصر** | درس للتحضير في ١٠–١٥ دقيقة: الإضاءة الاستهلالية، والمحاور الأربعة بآياتها وأحاديثها، وسؤال للحوار، ونشاط تطبيقي، ورادار الحماية، ورحلة الأسبوع. وتحت كل محور زر «للتوسع». |
| **كامل** | كل أقسام الدليل كما هي بدون تغيير، على شكل قوائم منسدلة. |
| **عرض** | شرائح تفاعلية بملء الشاشة. العناصر تظهر تدريجياً، والتنقل بالأسهم أو السحب. |
| **أنشطة** | كسر الجمود، وتفاعل سريع، وميدان التطبيق. |

## المزايا

- وضع نهاري وليلي، وتكبير الخط وتصغيره.
- فهرس جانبي وبحث في الصفحة الرئيسية، وأزرار السابق والتالي.
- زر «علّم كمُحضَّر» وزر «تابع من حيث وقفت» (يُحفظان في متصفح كل مستخدم فقط).
- خطوط: Tajawal للعربية، وPoppins للإنجليزية، وAmiri Quran للآيات.
- صفحات إضافية: مقدمة المشرف والأهداف، وميزان الأثر وخزانة المصادر.

## الاستخدام

افتح `index.html` في أي متصفح. الخطوط تُحمَّل من الإنترنت، وبدونه يعمل الموقع بخط النظام.

## النشر على GitHub Pages

1. ارفع `index.html` إلى فرع `main`.
2. من **Settings ← Pages** اختر **Deploy from a branch** ثم `main` و `/ (root)`.
3. انتظر دقيقة أو دقيقتين ثم افتح الرابط الذي يظهر.
